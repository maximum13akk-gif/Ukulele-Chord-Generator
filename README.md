 🎸 Ukulele Chord Generator — аккорды для укулеле в один клик

> «Четыре струны — бесконечная музыка»

**Ukulele Chord Generator** — это набор консольных утилит для отображения аппликатур аккордов на грифе укулеле.  
Программа показывает схемы зажатия аккордов для различных тональностей в стандартной настройке (GCEA) и других.

## 🚀 Особенности
- 🎵 Поддержка всех основных аккордов: мажор, минор, септаккорд, мажорный септаккорд, минорный септаккорд.
- 🎸 Отображение аппликатуры в виде ASCII-схемы с 4 струнами и 4 ладами.
- 🎚️ Настройка строя укулеле (GCEA, ADF#B, DGBE).
- 🔄 Смена позиции на грифе (открытая, баррэ, различные варианты).
- 📋 Список всех доступных аккордов с описанием.
- 🎨 Цветной вывод в терминале.
- 💾 Экспорт схемы аккорда в текстовый файл.
- 🔊 Подсказки по аппликатуре (какие пальцы использовать).

## 🛠️ Установка и запуск

Для каждого языка — минимальные зависимости (в основном стандартные библиотеки).

| Язык       | Зависимости                          | Команда запуска                         |
|------------|--------------------------------------|-----------------------------------------|
| Python     | стандартная библиотека               | `python ukulele_chords.py`              |
| Go         | стандартная библиотека               | `go run ukulele_chords.go`              |
| JavaScript | Node.js, никаких                     | `node ukulele_chords.js`                |
| Java       | стандартная библиотека               | `javac ukulele_chords.java && java ukulele_chords` |
| C#         | .NET (или mono)                      | `dotnet run`                            |
| Rust       | стандартная библиотека               | `cargo run`                             |
| Ruby       | стандартная библиотека               | `ruby ukulele_chords.rb`                |
| PHP        | стандартная библиотека               | `php ukulele_chords.php`                |

## 📖 Пример использования

```bash
$ python ukulele_chords.py --chord C --type major --tuning GCEA
Вывод:

text

   | | | | |
   | | | | |

Аппликатура:
  G: открыто
  C: открыто
  E: 1-й лад (палец 1)
  A: 3-й лад (палец 3)

Альтернативные варианты:
  C (баррэ на 5-м ладу)
  C (баррэ на 10-м ладу)
